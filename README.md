# Cube Recipes

Reusable workflows and community challenges for
[Cube](https://github.com/cubearc/cube) and
[Cube Play](https://github.com/cubearc/play).

A recipe composes existing Cube operations with explicit input/output types and
version requirements. Algorithms and operation contracts remain in Cube.
This repository is accepting its first contributions; a curated recipe collection
has not been published yet.

## Start

- [Write and check a recipe](docs/authoring.md).
- [Choose the right artifact](docs/index.md): recipe, challenge or private finding.
- Read the [Cube documentation](https://github.com/cubearc/cube/blob/main/docs/index.md)
  for installation and available operations.

Include the task, input, expected result and compatibility evidence with a
contribution. Use original or redistributable fixtures.
See [Contributing](CONTRIBUTING.md) for the shared documentation policy.

Track work in [GitHub Issues](https://github.com/cubearc/recipes/issues) and
[CubeArc Roadmap](https://github.com/orgs/cubearc/projects/1).
