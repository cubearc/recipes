# Recipe documentation

Read applicable instructions and the
[shared authoring guide](https://github.com/cubearc/docs/blob/main/content/contributing/documentation.md).
With a sibling docs checkout, prefer its `content/contributing/documentation.md`.

Document the task, explicit input, minimal invocation, expected typed output and
version requirements. Reuse canonical Cube and Play concepts through links.
Keep the README an entry point; put reusable explanations in the owning guide.

Validate changed recipe examples with the real Cube executable, including a
failing incompatible expected result. Update navigation and check links.
Distinguish published challenges from private local Play findings.

Respect review-only and planning-only requests. Report actual changes and evidence.
