# Recipes

Choose the artifact that matches your goal:

| Goal | Artifact |
| --- | --- |
| Repeat a data-transformation task | A versioned Cube recipe with explicit bindings and expected output. |
| Publish an activity with stages or hints | A challenge using the supported [Play challenge contract](https://github.com/cubearc/play/blob/main/docs/challenges.md). |
| Keep personal evidence and an explanation | A [private Play solution](https://github.com/cubearc/play/blob/main/docs/solutions.md) in your local investigation. |

Start with [write and check a recipe](authoring.md). This repository currently
contains authoring guidance; no curated workflow collection is claimed.
