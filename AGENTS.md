# Recipes repository instructions

- Write English. A recipe is a reusable workflow; a challenge is a generic activity.
- Follow the [shared documentation guide](https://github.com/cubearc/docs/blob/main/content/contributing/documentation.md).
  Keep the README an entry point and each explanation in its canonical product docs.
- Algorithms and versioned operation contracts belong to Cube. Do not duplicate
  implementations, signatures or operation catalogs here.
- Document original inputs, expected typed results and exact compatibility
  requirements. Validate examples against the real Cube CLI.
- Use focused Conventional Commits and GitHub Issues/CubeArc Roadmap for planning.
  Close work only after its accepted changes are integrated and verified.
